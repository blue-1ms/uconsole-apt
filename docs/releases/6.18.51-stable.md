# uConsole kernel 6.18.51 stable

This release promotes the exact `6.18.51-candidate.06` transaction to stable for
the ClockworkPi uConsole CM4 Lite on Ubuntu 26.04.

## Package transaction

- Runtime: `6.18.51-1002-uconsole`
- Kernel package version: `1:6.18.51-1002.1.uconsole.1`
- Tested and minimum platform: `uconsole-platform 0.1.25`
- Plymouth: `uconsole-plymouth-theme 0.1.2`
- Patched source commit: `3046f1352116cba8b20027b7bcf47bab9293cbcd`
- Candidate repository bundle SHA-256:
  `14d5833e4bf74e0db59009ab7f64d2774e92ab792bd16db53a2e1649cae8ae13`

The Debian packages remain split into image, modules, headers, buildinfo, meta,
platform and Plymouth packages. Stable promotion reused the tested package bytes
and generated new signed stable APT metadata; it did not rebuild a package.

## Hardware and rollback

The exact transaction passed package and signed-repository validation, CM4 Lite
display/backlight/DRM, keyboard and pointing devices, audio, PMIC/battery,
Wi-Fi/Bluetooth, basic USB and FAT mailbox checks. A controlled boot into the sole
N-1 kernel `7.1.4-1001-uconsole` passed, followed by recovery and automatic promote
back to 6.18.51. Both final boot trees contain the full 367-overlay set.

## Upgrade

Configure the repository using the README, then run:

```bash
sudo apt update
sudo uconsole-apt-health
sudo uconsole-kernel-policy-validate
sudo apt install uconsole-kernel uconsole-platform uconsole-plymouth-theme
sudo reboot
```

Allow the automatic `piboot-try` validation to finish. Do not edit
`/boot/firmware`, remove the N-1 packages, or interrupt package/initramfs hooks.
