# uConsole kernel 7.1.4 stable

This release promotes the exact, hardware-tested `7.1.4-candidate.04` package
bytes to stable for Ubuntu 26.04 arm64 on the ClockworkPi uConsole CM4 Lite.

## Release identity

- Runtime: `7.1.4-1001-uconsole`
- Kernel package version: `7.1.4-1001.1.uconsole.1`
- Platform package: `uconsole-platform 0.1.20`
- Patched source commit: `556fdcffd188f56281a328dda1dac0f1af737a71`
- Offline APT bundle SHA-256:
  `b12738c7c0ae49c625598adf7e62b961b966d59d085f0c90c05cdef40525eb43`

## What changed

- Rebases the uConsole CM4 support on upstream Raspberry Pi Linux 7.1.4.
- Preserves CWU50 old/new panel detection, OCP8178 backlight, AXP PMIC/battery,
  input and audio routing support.
- Carries the BCM2711 VC4/V3D DMA-zone fix.
- Replaces release-specific ABI whitelists with signed kernel receipts and A/B
  deployment state.
- Allows trusted Broadcom/Raspberry Pi firmware updates while precisely
  preventing Ubuntu boot-owner kernels from taking over the uConsole slots.

## Validation

The exact package set passed package, modules, headers, DT/overlay, initramfs,
signed APT, real `piboot-try` promotion, hardware, FAT mailbox and APT health
checks. A controlled boot into `7.1.3-1003-uconsole` and recovery to 7.1.4 also
passed. That 7.1.3 ABI remains the sole N-1 fallback.

## Install or update

Complete the repository setup in the main README, then run:

```bash
sudo apt update
sudo uconsole-apt-health
sudo apt install uconsole-kernel uconsole-platform uconsole-plymouth-theme
sudo reboot
```

Allow the automatic `piboot-try` validation/restart sequence to finish. Do not
edit `/boot/firmware` or remove the fallback kernel manually.
